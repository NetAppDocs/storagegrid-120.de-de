= Optionale Aufgaben
:allow-uri-read: 


* link:../admin/managing-tenants.html["Ein Mandantenkonto erstellen"] für das S3 Clientprotokoll, das zum Speichern von Objekten auf Ihrem StorageGRID System verwendet wird.
* link:../admin/controlling-storagegrid-access.html["Zugriff auf das Kontrollsystem"] durch das Konfigurieren von Gruppen und Benutzerkonten. Optional können Sie link:../admin/using-identity-federation.html["Eine föderierte Identitätsquelle konfigurieren"] (wie Active Directory oder OpenLDAP), um Administrationsgruppen und Benutzer zu importieren. Oder Sie können link:../admin/managing-users.html#create-a-local-user["Lokale Gruppen und Benutzer erstellen"].
* Integrieren und testen Sie die link:../s3/configuring-tenant-accounts-and-connections.html["S3 API"] Clientanwendungen, die Sie zum Hochladen von Objekten in Ihr StorageGRID System verwenden.
* link:../ilm/index.html["Die Regeln für das Informationslebenszyklusmanagement (ILM) und die ILM-Richtlinie konfigurieren"] die Sie zum Schutz von Objektdaten verwenden möchten.
* Wenn Ihre Installation Appliance Storage Nodes umfasst, kann SANtricity OS für die folgenden Aufgaben verwendet werden:
+
** Mit jedem StorageGRID Gerät verbinden.
** Empfang der AutoSupport-Daten überprüfen.
+
Siehe  https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/configuring-hardware.html["Hardware einrichten"^].



* Die link:../harden/index.html["StorageGRID Systemhärtungsrichtlinien"] sollten überprüft und befolgt werden, um Sicherheitsrisiken zu beseitigen.
* link:../monitor/email-alert-notifications.html["E-Mail-Benachrichtigungen für Systemwarnungen konfigurieren"].
