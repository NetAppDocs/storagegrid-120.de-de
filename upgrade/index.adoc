= StorageGRID Software aktualisieren
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Diese Anweisungen dienen zur Aktualisierung eines StorageGRID Systems auf eine neue Version.

Beim Upgrade werden alle Knoten in Ihrem StorageGRID System aktualisiert.


CAUTION: Das Upgrade sollte nicht gestartet werden, wenn dringend eine Erweiterung des Speicherplatzes zur Kapazitätserhöhung erforderlich ist (wenn der Speicher fast voll ist). Das Upgrade-Verfahren sollte zeitnah abgeschlossen werden. Falls eine Wiederherstellung erforderlich ist, ist der technische Support zu kontaktieren.
