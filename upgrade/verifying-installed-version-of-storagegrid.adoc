= Überprüfen Sie die installierte Version von StorageGRID, bevor Sie ein Upgrade durchführen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vor Beginn des Upgrades sollte überprüft werden, ob die vorherige Version von StorageGRID aktuell installiert ist und der neueste verfügbare Hotfix angewendet wurde.

.Über diese Aufgabe
Bevor Sie auf StorageGRID 12.0 aktualisieren, muss auf Ihrem Grid StorageGRID 11.9.0.8 oder höher installiert sein. Wenn Sie derzeit eine frühere Version von StorageGRID verwenden, müssen alle vorherigen Upgrade-Dateien zusammen mit den jeweils neuesten Hotfixes (dringend empfohlen) installiert werden, bis die aktuelle Version Ihres Grids mindestens StorageGRID 11.9.0.8 ist.

Ein möglicher Upgrade-Pfad ist in der <<example-upgrade-path,Beispiel>> dargestellt.


CAUTION: NetApp empfiehlt nachdrücklich, vor dem Upgrade auf die nächste Version für jede StorageGRID-Version den jeweils neuesten Hotfix anzuwenden und auch für jede neu installierte Version den neuesten Hotfix zu installieren. In einigen Fällen muss ein Hotfix angewendet werden, um das Risiko von Datenverlust zu vermeiden. Siehe  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp Downloads: StorageGRID"^] und die Versionshinweise zu jedem Hotfix für weitere Informationen.



[[verify-installed-version]]
== Installierte Version überprüfen

.Schritte
. Melden Sie sich beim Grid Manager mit einem link:../admin/web-browser-requirements.html["unterstützte Webbrowser"] an.
. Oben im Grid Manager *Hilfe* > *Über* auswählen.
. Es sollte sichergestellt sein, dass die *Version* 11.9.0.8 oder höher ist.
. Falls die *Version* nicht 11.9.0.8 oder höher ist, zu  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp Downloads: StorageGRID"^] wechseln, um die benötigten Upgrade- und Hotfix-Dateien herunterzuladen.
. link:../upgrade/index.html["Den Upgrade-Anweisungen ist zu folgen."] für jede heruntergeladene Version. link:../maintain/storagegrid-hotfix-procedure.html["Den neuesten Hotfix anwenden"] für jede Version (dringend empfohlen).


Im folgenden Upgrade-Beispiel finden sich weitere Informationen.



[[example-upgrade-pathexample-upgrade-to-storagegrid-12-0-from-version-11-8]]
== [[example-upgrade-path]]Beispiel: Upgrade auf StorageGRID 12.0 von Version 11.8

Das folgende Beispiel zeigt die Schritte zum Upgrade von StorageGRID Version 11.8 auf Version 11.9 in Vorbereitung auf ein StorageGRID 12.0 Upgrade.

Die Software wird in der folgenden Reihenfolge heruntergeladen und installiert, um das System für das Upgrade vorzubereiten:

. Upgrade auf die StorageGRID 11.8.0 Hauptversion.
. Der neueste StorageGRID 11.8.0._y_ Hotfix wird angewendet.
. Upgrade auf die StorageGRID 11.9.0 Hauptversion.
. Den StorageGRID 11.9.0.8 oder höher Hotfix anwenden.
