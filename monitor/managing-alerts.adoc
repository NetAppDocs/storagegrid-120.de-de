= Warnmeldungen in StorageGRID verwalten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das Alarmsystem bietet eine benutzerfreundliche Oberfläche zum Erkennen, Bewerten und Beheben von Problemen, die während des StorageGRID Betriebs auftreten können.

Warnmeldungen werden bei bestimmten Schweregraden ausgelöst, wenn die Bedingungen der Warnregel als erfüllt gelten. Wenn eine Warnmeldung ausgelöst wird, erfolgen die folgenden Aktionen:

* Ein Symbol für den Schweregrad der Warnung wird im Grid Manager auf dem Dashboard angezeigt, und die Anzahl der aktuellen Warnungen wird erhöht.
* Die Warnung wird auf der *Knoten* Übersichtsseite und auf der Registerkarte *Knoten* > *_node_* > *Übersicht* angezeigt.
* Eine E-Mail-Benachrichtigung wird versendet, sofern ein SMTP-Server konfiguriert und E-Mail-Adressen für die Empfänger angegeben wurden.
* Eine Simple Network Management Protocol (SNMP)-Benachrichtigung wird gesendet, vorausgesetzt, Sie haben den StorageGRID SNMP-Agent konfiguriert.


Sie können benutzerdefinierte Warnmeldungen erstellen, Warnmeldungen bearbeiten oder deaktivieren und Warnmeldungsbenachrichtigungen verwalten.
