= Registerkarte „StorageGRID-Objekte“ anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Registerkarte „Objekte“ bietet Informationen über link:../s3/index.html["S3-Ingest- und -Retrieve-Raten"].

Die Registerkarte „Objekte“ wird für jeden Storage Node, jeden Standort und das gesamte Grid angezeigt. Für Storage Nodes liefert die Registerkarte „Objekte“ außerdem Objektanzahlen und Informationen zu Metadatenabfragen und Hintergrundüberprüfungen.
