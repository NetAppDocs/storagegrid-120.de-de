= Warnungen in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Diese Referenz listet die Standardwarnungen auf, die im Grid Manager angezeigt werden. Empfohlene Maßnahmen sind in der Warnmeldung enthalten, die Sie erhalten.

Bei Bedarf lassen sich benutzerdefinierte Alarmregeln erstellen, die zu Ihrem Systemmanagement-Ansatz passen.

Einige der Standardwarnungen verwenden link:commonly-used-prometheus-metrics.html["Prometheus-Metriken"].

 a| 
Ausfall des Appliance Storage Controllers B
