= Auf StorageGRID MIB-Dateien zugreifen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
MIB-Dateien enthalten Definitionen und Informationen zu den Eigenschaften verwalteter Ressourcen und Dienste für die Knoten in Ihrem Grid. Es besteht Zugriff auf MIB-Dateien, die die Objekte und Benachrichtigungen für StorageGRID definieren. Diese Dateien können für die Überwachung Ihres Grids nützlich sein.

Weitere Informationen zu SNMP und MIB-Dateien sind unter link:using-snmp-monitoring.html["SNMP Überwachung"] verfügbar.



[[access-mib-files]]
== Zugriff auf MIB-Dateien

Führen Sie die folgenden Schritte aus, um auf die MIB-Dateien zuzugreifen.

.Schritte
. *Konfiguration* > *Überwachung* > *SNMP agent* auswählen.
. Wählen Sie auf der SNMP-Agent-Seite die Datei aus, die Sie herunterladen möchten:
+
** *NETAPP-STORAGEGRID-MIB.txt*: Definiert die Alarmtabelle und die Benachrichtigungen (Traps), die auf allen Admin-Nodes zugänglich sind.
** *ES-NETAPP-06-MIB.mib*: Definiert Objekte und Benachrichtigungen für E-Series-basierte Appliances.
** *MIB_1_10.zip*: Definiert Objekte und Benachrichtigungen für Appliances mit einer BMC Schnittstelle.
+

TIP: Sie können auch an folgendem Speicherort auf jedem StorageGRID Node auf MIB-Dateien zugreifen: `/usr/share/snmp/mibs`



. Zum Extrahieren der StorageGRID OIDs aus der MIB-Datei:
+
.. Die OID des Stamms der StorageGRID MIB erhalten:
+
`root@user-adm1:~ # snmptranslate -On -IR storagegrid`

+
Ergebnis: `.1.3.6.1.4.1.789.28669` (`28669` ist immer die OID für StorageGRID)

.. Im gesamten Baum nach der StorageGRID-OID mit `grep` suchen (unter Verwendung von  `paste` zum Verbinden der Zeilen):
+
`root@user-adm1:~ # snmptranslate -Tso | paste -d " " - - | grep 28669`

+

TIP: Der  `snmptranslate`Befehl bietet zahlreiche Optionen, die für die Untersuchung der MIB nützlich sind. Dieser Befehl ist auf jedem StorageGRID Node verfügbar.
