= Was und wann in StorageGRID überwacht werden sollte
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Auch wenn das StorageGRID System bei Fehlern oder dem Ausfall von Teilen des Grids weiterhin funktionieren kann, sollten potenzielle Probleme überwacht und behoben werden, bevor sie die Effizienz oder Verfügbarkeit des Grids beeinträchtigen.

.Bevor Sie beginnen
* Sie sind mit einem link:../admin/web-browser-requirements.html["unterstützte Webbrowser"] beim Grid Manager angemeldet.
* Du hast link:../admin/admin-group-permissions.html["spezifische Zugriffsberechtigungen"].
