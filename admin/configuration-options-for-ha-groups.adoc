= Konfigurationsoptionen für StorageGRID High-Availability-Gruppen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die folgenden Diagramme zeigen Beispiele für verschiedene Möglichkeiten, wie Sie Hochverfügbarkeitsgruppen (HA-Gruppen) konfigurieren können. Jede Option hat Vor- und Nachteile.

In den Diagrammen kennzeichnet Blau die primäre Schnittstelle in der HA-Gruppe und Gelb die Backup-Schnittstelle in der HA-Gruppe.

image:high_availability_examples.png["HA Beispiele"]

Die Tabelle fasst die Vorteile jeder im Diagramm dargestellten HA Konfiguration zusammen.

[cols="1a,2a,2a"]
|===
| Konfiguration | Vorteile | Nachteile 


 a| 
Active-Backup HA
 a| 
* Verwaltet von StorageGRID ohne externe Abhängigkeiten.
* Schnelles Failover.

 a| 
* Nur ein Knoten in einer HA-Gruppe ist aktiv. Mindestens ein Knoten pro HA-Gruppe ist im Leerlauf.




 a| 
DNS Round Robin
 a| 
* Erhöhter Gesamtdurchsatz.
* Keine Leerlauf-Hosts.

 a| 
* Langsames Failover, das vom Verhalten des Clients abhängen kann.
* Erfordert die Konfiguration von Hardware außerhalb von StorageGRID.
* Erfordert einen vom Kunden implementierten Gesundheitscheck.




 a| 
Active-Active-HA
 a| 
* Der Datenverkehr wird auf mehrere HA-Gruppen verteilt.
* Hoher Gesamtdurchsatz, der mit der Anzahl der HA-Gruppen skaliert.
* Schnelles Failover.

 a| 
* Komplexer zu konfigurieren.
* Erfordert die Konfiguration von Hardware außerhalb von StorageGRID.
* Erfordert einen vom Kunden implementierten Gesundheitscheck.


|===
