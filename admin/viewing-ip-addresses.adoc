= IP-Adressen in StorageGRID anzeigen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können die IP-Adresse jedes Grid-Knotens in Ihrem StorageGRID System anzeigen. Diese IP-Adresse kann dann verwendet werden, um sich an dem Grid-Knoten über die Befehlszeile anzumelden und verschiedene Wartungsverfahren durchzuführen.

.Bevor Sie beginnen
Sie sind mit einem link:../admin/web-browser-requirements.html["unterstützte Webbrowser"] beim Grid Manager angemeldet.

.Über diese Aufgabe
Informationen zum Ändern von IP-Adressen sind unter link:../maintain/configuring-ip-addresses.html["IP-Adressen konfigurieren"] verfügbar.

.Schritte
. Wählen Sie *Nodes* > *_grid node_* > *Overview*.
. Rechts neben dem Titel „IP Addresses“ die Option *Show more* auswählen.
+
Die IP-Adressen für diesen Grid-Knoten sind in einer Tabelle aufgeführt.
