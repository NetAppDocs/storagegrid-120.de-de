= Erstellen Sie Unternehmensanwendungen in Entra ID für StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Entra ID wird verwendet, um eine Unternehmensanwendung für jeden Admin-Knoten in Ihrem System zu erstellen.

.Bevor Sie beginnen
* Sie haben mit der Konfiguration von Single Sign-On für StorageGRID begonnen und *Entra ID* als SSO-Typ ausgewählt.
* Sie haben link:../admin/configure-sso.html#enter-sandbox-mode["Sandbox-Modus wurde aktiviert"] im Grid Manager.
* Sie haben den *Enterprise application name* für jeden Admin-Node in Ihrem System. Diese Werte können aus der Admin-Node-Detailtabelle auf der Seite „SSO konfigurieren“ kopiert werden.
+

NOTE: Sie müssen für jeden Admin Node in Ihrem StorageGRID System eine Unternehmensanwendung erstellen. Eine eigene Unternehmensanwendung für jeden Admin Node stellt sicher, dass sich Benutzer sicher bei jedem Admin Node anmelden und wieder ausloggen können.

* Sie haben Erfahrung in der Erstellung von Unternehmensanwendungen in Entra ID.
* Sie besitzen ein Entra ID Konto mit einem aktiven Abonnement.
* Sie verfügen über eine der folgenden Rollen im Entra ID Konto: Globaler Administrator, Cloud-Anwendungsadministrator, Anwendungsadministrator oder Eigentümer des Dienstprinzipals.




[[access-entra-id]]
== Entra ID aufrufen

.Schritte
. Melden Sie sich bei der https://portal.azure.com["Azure Portal"^]an.
. Navigieren Sie zu  https://portal.azure.com/#blade/Microsoft_AAD_IAM/ActiveDirectoryMenuBlade["Entra ID"^].
. Wählen Sie  https://portal.azure.com/#blade/Microsoft_AAD_IAM/StartboardApplicationsMenuBlade/Overview/menuId/["Unternehmensanwendungen"^].




[[create-enterprise-applications-and-save-storagegrid-sso-configuration]]
== Unternehmensanwendungen erstellen und StorageGRID SSO-Konfiguration speichern

Um die SSO-Konfiguration für Entra ID in StorageGRID zu speichern, ist es erforderlich, mit Entra ID für jeden Admin-Knoten eine Unternehmensanwendung zu erstellen. Die Föderationsmetadaten-URLs werden aus Entra ID kopiert und in die entsprechenden Felder für *Federation metadata URL* auf der Seite „SSO konfigurieren“ eingefügt.

.Schritte
. Die folgenden Schritte sind für jeden Admin Node zu wiederholen.
+
.. Im Bereich Entra ID Enterprise-Anwendungen die Option *Neue Anwendung* auswählen.
.. *Eigene Anwendung erstellen* auswählen.
.. Für den Namen ist der *Enterprise application name* einzugeben, der aus der Tabelle „Admin-Knotendetails“ auf der Seite „SSO konfigurieren“ kopiert wurde.
.. Die Option *Integrate any other application you don't find in the gallery (Non-gallery)* bleibt ausgewählt.
.. Wählen Sie *Create*.
.. Wählen Sie den Link *Los geht's* im Feld *2. Einmalanmeldung einrichten* oder den Link *Einmalanmeldung* in der linken Marge.
.. Das Kontrollkästchen *SAML* auswählen.
.. Kopieren Sie die *App Federation Metadata Url*, die Sie unter *Schritt 3 SAML-Signaturzertifikat* finden.
.. Rufen Sie die Seite „SSO konfigurieren“ auf und fügen Sie die URL in das Feld „URL der Föderationsmetadaten“ ein, das dem *Enterprise application name* entspricht, den Sie verwendet haben.


. Nachdem Sie für jeden Admin-Knoten eine Metadaten-URL für die Föderation eingefügt und alle anderen erforderlichen Änderungen an der SSO-Konfiguration vorgenommen haben, auf der Seite „SSO konfigurieren“ *Speichern* auswählen.




[[download-saml-metadata-for-every-admin-node]]
== SAML-Metadaten für jeden Admin-Node herunterladen

Nachdem die SSO-Konfiguration gespeichert wurde, kann für jeden Admin-Knoten in Ihrem StorageGRID System eine SAML-Metadatendatei heruntergeladen werden.

.Schritte
. Diese Schritte sind für jeden Admin Node zu wiederholen.
+
.. Bei StorageGRID vom Admin-Knoten aus anmelden.
.. *Konfiguration* > *Zugriffskontrolle* > *Single sign-on* auswählen.
.. Die Schaltfläche auswählen, um die SAML-Metadaten für diesen Admin-Knoten herunterzuladen.
.. Die Datei speichern, die anschließend in Entra ID hochgeladen wird.






[[upload-saml-metadata-to-each-enterprise-application]]
== SAML-Metadaten in jede Unternehmensanwendung hochladen

Nach dem Herunterladen einer SAML-Metadatendatei für jeden StorageGRID Admin Node sind in Entra ID die folgenden Schritte durchzuführen:

.Schritte
. Zurück zum Azure Portal.
. Diese Schritte sind für jede Unternehmensanwendung zu wiederholen:
+

NOTE: Möglicherweise ist es erforderlich, die Seite „Unternehmensanwendungen“ zu aktualisieren, damit zuvor hinzugefügte Anwendungen in der Liste angezeigt werden.

+
.. Zur Eigenschaftenseite der Unternehmensanwendung wechseln.
.. *Zuweisung erforderlich* auf *Nein* setzen (es sei denn, die Zuweisungen sollen separat konfiguriert werden).
.. Zur Seite für die Einmalanmeldung wechseln.
.. Die SAML-Konfiguration abschließen.
.. Die Schaltfläche *Metadatendatei hochladen* auswählen und die SAML-Metadatendatei auswählen, die für den entsprechenden Admin Node heruntergeladen wurde.
.. Nachdem die Datei geladen wurde, *Speichern* auswählen und anschließend *X*, um das Fenster zu schließen. Die Seite „Single Sign-On mit SAML einrichten“ wird wieder angezeigt.
