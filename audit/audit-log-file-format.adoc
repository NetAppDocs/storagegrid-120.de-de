= Erfahren Sie mehr über das Format von Revisionsprotokolldateien in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die Revisionsprotokoll Logdateien befinden sich auf jedem Admin Node und enthalten eine Sammlung einzelner Audit-Meldungen.

Jede Revisionsprotokollmeldung enthält Folgendes:

* Die koordinierte Weltzeit (UTC) des Ereignisses, das die Revisionsprotokollmeldung (ATIM) ausgelöst hat, im ISO 8601-Format, gefolgt von einem Leerzeichen:
+
`_YYYY-MM-DDTHH:MM:SS.UUUUUU_`, wobei `_UUUUUU_` Mikrosekunden sind.

* Die Prüfmeldung selbst, in eckigen Klammern eingeschlossen und beginnend mit `AUDT`.

Im Standardformat sind die Audit-Meldungen in den Revisionsprotokolldateien nicht leicht lesbar oder interpretierbar. Mit link:using-audit-explain-tool.html["audit-explain Tool"] lassen sich vereinfachte Zusammenfassungen der Audit-Meldungen im Revisionsprotokoll erhalten. Mit link:using-audit-sum-tool.html["audit-sum Tool"] kann zusammengefasst werden, wie viele Schreib-, Lese- und Löschvorgänge protokolliert wurden und wie lange diese Vorgänge dauerten.
