= StorageGRID ILM-Revisionsprotokollmeldungen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Die zur ILM-Auditkategorie gehörenden Audit-Meldungen werden für Ereignisse im Zusammenhang mit Information Lifecycle Management (ILM)-Operationen verwendet.

[cols="1a,3a,1a"]
|===
| Code | Nachrichtentitel und -beschreibung | Siehe 


 a| 
IDEL
 a| 
ILM Initiated Delete: Diese Prüfmeldung wird generiert, wenn ILM den Löschvorgang eines Objekts startet.
 a| 
link:idel-ilm-initiated-delete.html["IDEL: ILM initiierte Löschung"]



 a| 
LKCU
 a| 
Bereinigung überschriebener Objekte. Diese Audit-Meldung wird generiert, wenn ein überschriebenes Objekt automatisch entfernt wird, um Speicherplatz freizugeben.
 a| 
link:lkcu-overwritten-object-cleanup.html["LKCU: Bereinigung überschriebener Objekte"]



 a| 
ORLM
 a| 
Objektregeln erfüllt: Diese Prüfmeldung wird generiert, wenn Objektdaten wie in den ILM-Regeln angegeben gespeichert werden.
 a| 
link:orlm-object-rules-met.html["ORLM: Objektregeln erfüllt"]

|===
