= Wenn Revisionsprotokollmeldungen in StorageGRID generiert werden
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bei jedem Import, Abruf oder Löschen eines Objekts werden Audit-Meldungen generiert. Diese Transaktionen lassen sich im Revisionsprotokoll anhand der S3-API-spezifischen Audit-Meldungen identifizieren.

Revisionsprotokollmeldungen sind über protokollspezifische Kennungen miteinander verknüpft.

[cols="1a,1a"]
|===
| Protokoll | Code 


 a| 
Verknüpfung von S3-Operationen
 a| 
S3BK (Bucket), S3KY (Key) oder beides



 a| 
Verknüpfung interner Abläufe
 a| 
CBID (interner Objektbezeichner)

|===


[[timing-of-audit-messages]]
== Zeitpunkt der Revisionsprotokollmeldungen

Aufgrund von Faktoren wie Zeitunterschieden zwischen den Grid-Knoten, der Objektgröße und Netzwerkverzögerungen kann die Reihenfolge der von den verschiedenen Diensten generierten Revisionsprotokollmeldungen von der in den Beispielen in diesem Abschnitt gezeigten Reihenfolge abweichen.
