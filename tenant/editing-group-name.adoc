= Bearbeiten Sie einen Mandantengruppennamen in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können den Anzeigenamen einer Gruppe bearbeiten. Sie können den eindeutigen Namen einer Gruppe nicht bearbeiten.

.Bevor Sie beginnen
* Sie sind beim Tenant Manager mit einem link:../admin/web-browser-requirements.html["unterstützte Webbrowser"] angemeldet.
* Sie gehören einer Benutzergruppe an, die über die Root-Zugriffsberechtigung verfügt. Siehe link:tenant-management-permissions.html["Berechtigungen zur Mieterverwaltung"].


.Schritte
. *Zugriffsverwaltung* > *Gruppen* auswählen.
. Aktivieren Sie das Kontrollkästchen für die Gruppe, deren Anzeigename bearbeitet werden soll.
. *Aktionen* > *Gruppennamen bearbeiten* auswählen.
+
Das Dialogfeld „Gruppennamen bearbeiten“ wird angezeigt.

+
image:edit_group_name.png["Gruppenname bearbeiten"]

. Wenn eine lokale Gruppe bearbeitet wird, kann der Anzeigename bei Bedarf aktualisiert werden.
+
Der eindeutige Name einer Gruppe kann nicht geändert werden. Der Anzeigename einer Verbundgruppe kann nicht bearbeitet werden.

. Wählen Sie *Save changes*.
+
In der oberen rechten Ecke der Seite erscheint eine Bestätigungsmeldung.
