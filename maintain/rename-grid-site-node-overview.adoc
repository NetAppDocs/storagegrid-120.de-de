= Verwenden Sie die StorageGRID-Umbenennungsprozedur
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Bei Bedarf können Sie die im Grid Manager angezeigten Anzeigenamen für das gesamte Grid, jeden Standort und jeden Node ändern. Die Anzeigenamen lassen sich jederzeit und sicher aktualisieren.



[[what-is-the-rename-procedure]]
== Wie läuft die Umbenennung ab?

Bei der erstmaligen Installation von StorageGRID wird ein Name für das Grid, jeden Standort und jeden Node angegeben. Diese anfänglichen Namen werden als _Systemnamen_ bezeichnet und sind die Namen, die zunächst in StorageGRID angezeigt werden.

Systemnamen sind für interne StorageGRID-Operationen erforderlich und können nicht geändert werden. Es besteht jedoch die Möglichkeit, mithilfe der Umbenennungsprozedur neue _Anzeigenamen_ für das Grid, jeden Standort und jeden Node zu definieren. Diese Anzeigenamen erscheinen an verschiedenen Stellen in StorageGRID anstelle von (oder in manchen Fällen zusätzlich zu) den zugrunde liegenden Systemnamen.

Das Umbenennungsverfahren dient dazu, Tippfehler zu korrigieren, eine andere Namenskonvention umzusetzen oder anzuzeigen, dass ein Standort und alle zugehörigen Nodes verlegt wurden. Im Gegensatz zu Systemnamen können Anzeigenamen jederzeit und ohne Auswirkungen auf den StorageGRID Betrieb aktualisiert werden.

[[display-name-requirements]]
== Anforderungen an den Anzeigenamen

Vor der Verwendung dieses Verfahrens sollten die Anforderungen an Anzeigenamen überprüft werden.



[[display-names-for-nodes]]
=== Anzeigenamen für Nodes

Die Anzeigenamen für Knoten müssen diesen Regeln entsprechen:

* Muss im gesamten StorageGRID System eindeutig sein.
* Darf nicht mit dem Systemnamen eines anderen Elements in Ihrem StorageGRID System übereinstimmen.
* Muss mindestens 1 und höchstens 32 Zeichen enthalten.
* Kann Zahlen, Bindestriche (-) sowie Groß- und Kleinbuchstaben enthalten.
* Kann mit einem Buchstaben oder einer Zahl beginnen oder enden, darf jedoch nicht mit einem Bindestrich beginnen oder enden.
* Es können nicht nur Zahlen sein.
* Es wird nicht zwischen Groß- und Kleinschreibung unterschieden. Beispielsweise werden  `DC1-ADM` und  `dc1-adm` als Duplikate betrachtet.


Sie können einen Knoten mit einem Anzeigenamen umbenennen, der zuvor von einem anderen Knoten verwendet wurde, sofern die Umbenennung nicht zu einem doppelten Anzeigenamen oder Systemnamen führt.



[[display-names-for-grid-and-sites]]
=== Anzeigenamen für Grid und Standorte

Für die Anzeigenamen für das Grid und die Standorte gelten dieselben Regeln mit folgenden Ausnahmen:

* Kann Leerzeichen enthalten.
* Kann folgende Sonderzeichen enthalten: `= - _ : , . @ !`
* Kann mit Sonderzeichen, einschließlich Bindestrichen, beginnen und enden.
* Kann nur aus Zahlen oder Sonderzeichen bestehen.




[[display-name-best-practices]]
== Best Practices für Anzeigenamen

Wenn die Umbenennung mehrerer Elemente vorgesehen ist, sollte das allgemeine Namenskonvention vor der Durchführung dieses Verfahrens dokumentiert werden. Ein System, das sicherstellt, dass die Namen eindeutig, konsistent und auf einen Blick verständlich sind, ist zu entwickeln.

Es kann jede Namenskonvention verwendet werden, die den organisatorischen Anforderungen entspricht. Dabei bieten sich die folgenden grundlegenden Vorschläge für den Inhalt an:

* *Standortkennung*: Bei mehreren Standorten wird jedem Node-Name ein Standortcode hinzugefügt.
* *Knotentyp*: Knotennamen geben typischerweise den Knotentyp an. Es können Abkürzungen wie  `s`,  `adm` und  `gw` (Speicherknoten, Verwaltungsknoten und Gateway-Knoten) verwendet werden.
* *Knotennummer*: Wenn eine Website mehr als einen Knoten eines bestimmten Typs enthält, sollte jedem Node-Name eine eindeutige Nummer hinzugefügt werden.


Es empfiehlt sich, vor dem Hinzufügen spezifischer Details zu Namen, die sich im Laufe der Zeit ändern können, sorgfältig abzuwägen. Beispielsweise sollten IP-Adressen nicht in Node-Namen aufgenommen werden, da sich diese Adressen ändern können. Ebenso können sich Rack-Standorte oder Appliance-Modellnummern ändern, wenn Geräte versetzt oder die Hardware aufgerüstet wird.
