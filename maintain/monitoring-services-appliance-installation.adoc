= Installation der StorageGRID-Services-Appliance überwachen
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Der StorageGRID Appliance Installer zeigt den Status bis zum Abschluss der Installation an. Nach Abschluss der Softwareinstallation wird die Appliance neu gestartet.

.Schritte
. Der Installationsfortschritt kann in der Menüleiste unter *Installation überwachen* eingesehen werden.
+
Auf der Seite „Monitor Installation“ wird der Installationsfortschritt angezeigt.

+
Die blaue Statusleiste zeigt an, welche Aufgabe gerade ausgeführt wird. Grüne Statusleisten zeigen Aufgaben an, die erfolgreich abgeschlossen wurden.

+

NOTE: Das Installationsprogramm stellt sicher, dass Aufgaben, die bei einer vorherigen Installation abgeschlossen wurden, nicht erneut ausgeführt werden. Bei einer erneuten Installation werden alle Aufgaben, die nicht erneut ausgeführt werden müssen, mit einer grünen Statusleiste und dem Status „Übersprungen“ angezeigt.

. Den Fortschritt der ersten beiden Installationsphasen überprüfen.
+
** *1. Speicher konfigurieren*
+
In diesem Schritt entfernt das Installationsprogramm alle vorhandenen Konfigurationen von den Laufwerken und konfiguriert die Host-Einstellungen.

** *2. Betriebssystem installieren*
+
Während dieser Phase kopiert das Installationsprogramm das Basisbetriebssystem-Image für StorageGRID vom primären Admin Node auf die Appliance oder installiert das Basisbetriebssystem aus dem Installationspaket für den primären Admin Node.



. Der Installationsfortschritt sollte weiterhin überwacht werden, bis eines der folgenden Ereignisse eintritt:
+
** Für Appliance-Gateway-Knoten oder nicht-primäre Appliance-Admin-Knoten wird die Phase *Install StorageGRID* angehalten und eine Meldung auf der integrierten Konsole angezeigt, die dazu auffordert, diesen Knoten auf dem Admin-Knoten mithilfe des Grid Managers zu genehmigen.
** Für Appliance-primäre Admin-Knoten erscheint eine fünfte Phase (Load StorageGRID Installer). Wenn die fünfte Phase länger als 10 Minuten andauert, sollte die Seite manuell aktualisiert werden.
