= Warnungen zur Wiederherstellung des Systemlaufwerks des StorageGRID-Speicherknotens
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vor der Wiederherstellung eines ausgefallenen Systemlaufwerks eines Storage Node sollten die allgemeinen link:warnings-and-considerations-for-grid-node-recovery.html["Warnungen und Überlegungen zur Wiederherstellung von Grid-Knoten"] sowie die folgenden spezifischen Warnhinweise geprüft werden.

Speicherknoten verfügen über eine Cassandra Datenbank, die Objektmetadaten enthält. Die Cassandra Datenbank muss möglicherweise neu aufgebaut werden, wenn:

* Ein Speichervolumen fällt aus und wird wiederhergestellt.
* Das Systemlaufwerk und ein oder mehrere Speichervolumes fallen aus und werden wiederhergestellt.


Beim Neuaufbau von Cassandra verwendet das System Informationen von anderen Storage Nodes. Wurde Cassandra erst kürzlich neu aufgebaut, sind die Cassandra-Daten möglicherweise noch nicht im gesamten Grid konsistent. Wenn zu viele Storage Nodes offline sind:

* Einige Cassandra-Daten sind möglicherweise nicht verfügbar.
* Es kann zu Datenverlust kommen.



CAUTION: Wenn mehr als ein Storage Node ausgefallen ist (oder offline ist), sollte der technische Support kontaktiert werden. Die folgende Wiederherstellungsprozedur sollte nicht durchgeführt werden. Es könnte zu Datenverlust kommen. Weitere Informationen sind unter link:how-site-recovery-is-performed-by-technical-support.html["Wie der technische Support eine Website wiederherstellt"] zu finden.


CAUTION: Befindet sich dieser Storage Node im schreibgeschützten Wartungsmodus, um die Wiederherstellung von Objekten durch einen anderen Storage Node mit ausgefallenen Speichervolumes zu ermöglichen, sollten die Volumes auf dem Storage Node mit den ausgefallenen Speichervolumes wiederhergestellt werden, bevor dieser ausgefallene Storage Node wiederhergestellt wird. Siehe die Anweisungen zu link:recovering-from-storage-volume-failure-where-system-drive-is-intact.html["Wiederherstellung nach einem Ausfall des Storage-Volumes, wenn das Systemlaufwerk intakt ist"].


CAUTION: Wenn die ILM-Regeln so konfiguriert sind, dass nur eine replizierte Kopie gespeichert wird und sich die Kopie auf einem ausgefallenen Speichervolume befindet, ist eine Wiederherstellung des Objekts nicht möglich.
