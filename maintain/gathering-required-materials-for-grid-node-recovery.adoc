= Sammeln Sie die benötigten Materialien für die Wiederherstellung des StorageGRID-Grid-Knotens
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vor der Durchführung von Wartungsarbeiten muss sichergestellt sein, dass die notwendigen Materialien zur Wiederherstellung eines ausgefallenen Netzknotens vorhanden sind.

[cols="1a,2a"]
|===
| Artikel | Hinweise 


 a| 
StorageGRID Installationsarchiv
 a| 
Wenn ein Grid-Knoten wiederhergestellt werden muss, ist <<download-and-extract-install-files-recover,StorageGRID Installationsdateien herunterladen>> für Ihre Plattform erforderlich.

*Hinweis:* Es ist nicht erforderlich, Dateien herunterzuladen, wenn ausgefallene Speichervolumes auf einem Storage Node wiederhergestellt werden.



 a| 
Service Laptop
 a| 
Der Dienstlaptop muss Folgendes aufweisen:

* Netzwerkport
* SSH-Client (zum Beispiel PuTTY)
* link:../admin/web-browser-requirements.html["Unterstützte Webbrowser"]




 a| 
Wiederherstellungspaket `.zip`-Datei
 a| 
Eine Kopie der aktuellsten Wiederherstellungspaket `.zip`-Datei erhalten:
`sgws-recovery-package-_id-revision_.zip`

Der Inhalt der  `.zip` Datei wird bei jeder Änderung des Systems aktualisiert. Es wird empfohlen, die aktuellste Version des Wiederherstellungspakets nach solchen Änderungen an einem sicheren Ort aufzubewahren. Die aktuellste Kopie dient zur Wiederherstellung nach Grid-Ausfällen.

Nach der Anmeldung an einem beliebigen Admin-Knoten steht im Grid Manager die Option zum Herunterladen eines Wiederherstellungspakets zur Verfügung. *Wartung* > *System* > *Wiederherstellungspaket* auswählen.

Falls kein Zugriff auf den Grid Manager möglich ist, befinden sich verschlüsselte Kopien des Wiederherstellungspakets auf einigen Storage Nodes, die den ADC-Service enthalten. Auf jedem Storage Node ist an folgendem Speicherort nach dem Wiederherstellungspaket zu suchen: `/var/local/install/sgws-recovery-package-_grid-id_-_revision_.zip.gpg` Das Wiederherstellungspaket mit der höchsten Revisionsnummer ist zu verwenden.



 a| 
`Passwords.txt` Datei
 a| 
Enthält die Passwörter, die für den Zugriff auf Grid-Knoten über die Befehlszeile erforderlich sind. Im Wiederherstellungspaket enthalten.



 a| 
Bereitstellungspassphrase
 a| 
Die Passphrase wird bei der Erstinstallation des StorageGRID-Systems erstellt und dokumentiert. Die Bereitstellungspassphrase ist nicht in der  `Passwords.txt` Datei.



 a| 
Aktuelle Dokumentation für Ihre Plattform
 a| 
Die Dokumentation befindet sich auf der Website des Plattformanbieters.

Die aktuell unterstützten Versionen Ihrer Plattform sind in der  https://imt.netapp.com/matrix/#welcome["NetApp Interoperabilitätsmatrix-Tool"^] aufgeführt.

|===


[[download-and-extract-storagegrid-installation-files]]
== StorageGRID Installationsdateien herunterladen und extrahieren

.[[download-and-extract-install-files-recover]]
Laden Sie die Software herunter und extrahieren Sie die Dateien, es sei denn, Sie sind link:recovering-from-storage-node-failures.html["Wiederherstellung ausgefallener Speichervolumes auf einem Storage Node"].

Es ist die Version von StorageGRID zu verwenden, die aktuell auf dem Grid ausgeführt wird.

.Schritte
. Ermitteln, welche Version der Software aktuell installiert ist. Oben im Grid Manager das Hilfesymbol auswählen und *Über* wählen.
. Gehe zu https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp Downloads-Seite für StorageGRID"^].
. Die Version von StorageGRID, die aktuell im Grid ausgeführt wird, auswählen.
+
StorageGRID Softwareversionen haben dieses Format: `11.x.y`.

. Melden Sie sich mit dem Benutzernamen und Passwort für Ihr NetApp-Konto an.
. Die Endbenutzer-Lizenzvereinbarung anzeigen, das Kontrollkästchen auswählen und anschließend *Akzeptieren & Fortfahren* wählen.
. Wählen Sie in der Spalte *Install StorageGRID* auf der Downloadseite die  `.tgz` oder  `.zip` Datei für Ihre Plattform aus.
+
Die in der Installationsarchivdatei angegebene Version muss mit der Version der aktuell installierten Software übereinstimmen.

+
Die  `.zip` Datei wird bei Verwendung von Windows genutzt.

+
