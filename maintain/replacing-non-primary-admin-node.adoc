= Ersetzen Sie den nicht primären StorageGRID Admin Node
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Um einen nicht primären Admin-Knoten wiederherzustellen, muss zunächst die physische oder virtuelle Hardware ersetzt werden.

Ein ausgefallener nicht-primärer Admin-Knoten kann durch einen nicht-primären Admin-Knoten ersetzt werden, der auf derselben Plattform läuft, oder ein nicht-primärer Admin-Knoten, der auf VMware oder einem Linux-Host läuft, kann durch einen nicht-primären Admin-Knoten ersetzt werden, der auf einer Services Appliance gehostet wird.

Verwenden Sie das Verfahren, das der von Ihnen ausgewählten Ersatzplattform für den Knoten entspricht. Nach Abschluss des Knotenaustauschverfahrens (das für alle Knotentypen geeignet ist) führt dieses Verfahren Sie zum nächsten Schritt für die Wiederherstellung des nicht primären Admin Node.

| Ersatzplattform | Verfahren 


 a|

 a| 
link:all-node-types-replacing-vmware-node.html["Einen VMware-Knoten ersetzen"]



 a|

 a| 
link:all-node-types-replacing-linux-node.html["Einen Linux-Knoten ersetzen"]



 a|

 a| 
link:replacing-failed-node-with-services-appliance.html["Austausch eines Servicegeräts"]



 a| 
OpenStack
 a| 
NetApp-bereitgestellte virtuelle Maschinen-Festplattendateien und Skripte für OpenStack werden für Wiederherstellungsvorgänge nicht mehr unterstützt. Wenn ein Knoten in einer OpenStack-Bereitstellung wiederhergestellt werden muss, stehen die Dateien für das jeweilige Linux-Betriebssystem zum Download bereit. Anschließend ist das Verfahren für link:all-node-types-replacing-linux-node.html["einen Linux Knoten ersetzen"] zu befolgen.
