= Was ist das StorageGRID ADC-Quorum?
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Es kann vorkommen, dass bestimmte Storage Nodes an einem Standort nicht außer Betrieb genommen werden können, wenn nach der Außerbetriebnahme zu wenige Administrative Domain Controller (ADC)-Dienste übrig bleiben.

Der ADC-Dienst, der auf einigen Storage Nodes verfügbar ist, verwaltet Informationen zur Grid-Topologie und stellt Konfigurationsdienste für das Grid bereit. Das StorageGRID System erfordert, dass an jedem Standort und zu jeder Zeit ein Quorum an ADC-Diensten verfügbar ist.

Ein Storage Node kann nicht außer Betrieb genommen werden, wenn durch das Entfernen des Knotens das ADC-Quorum nicht mehr erfüllt wäre. Um das ADC-Quorum während einer Außerbetriebnahme zu erfüllen, müssen an jedem Standort mindestens drei Storage Nodes den ADC-Service haben. Wenn ein Standort über mehr als drei Storage Nodes mit dem ADC-Service verfügt, muss nach der Außerbetriebnahme die einfache Mehrheit dieser Knoten weiterhin verfügbar sein: `((0.5 * _Storage Nodes with ADC_) + 1)`


CAUTION: Seien Sie vorsichtig beim Außerbetriebnehmen von Storage Nodes in einem Grid mit softwarebasierten Metadaten-only-Knoten. Wenn alle Knoten außer Betrieb genommen werden, die _sowohl_ Objekte als auch Metadaten speichern, wird die Möglichkeit, Objekte im Grid zu speichern, entfernt. Siehe link:../primer/what-storage-node-is.html#types-of-storage-nodes["Arten von Speicherknoten"] für weitere Informationen zu Metadaten-only Storage Nodes.

Angenommen, ein Standort umfasst derzeit sechs Storage Nodes mit ADC-Services und Sie möchten drei Storage Nodes außer Betrieb nehmen. Aufgrund der ADC-Quorumsanforderung sind zwei Außerbetriebnahmeverfahren erforderlich, wie folgt:

* Im ersten Stilllegungsvorgang muss sichergestellt werden, dass vier Storage Nodes mit ADC-Services weiterhin verfügbar sind `((0.5 * 6) + 1)`. Das bedeutet, dass zunächst nur zwei Storage Nodes stillgelegt werden können.
* Im zweiten Stilllegungsvorgang können Sie den dritten Storage Node entfernen, da das ADC-Quorum nun nur noch drei verfügbare ADC-Services erfordert: `((0.5 * 4) + 1)`.


Wenn Sie einen Speicherknoten außer Betrieb nehmen müssen, können Sie die ADC-Quorumsanforderung weiterhin erfüllen, indem Sie link:../release-notes/changes-to-grid-management-api.html#new-private-endpoints-for-move-adc["Verschieben des ADC-Dienstes auf einen anderen Storage Node am selben Standort"] oder einen neuen Speicherknoten in einer link:../expand/index.html["Erweiterung"] hinzufügen und festlegen, dass dieser über einen ADC-Dienst verfügen soll. Anschließend können Sie den vorhandenen Speicherknoten außer Betrieb nehmen, ohne das Quorum zu beeinträchtigen.
