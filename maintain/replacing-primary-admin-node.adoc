= Ersetzen Sie den primären StorageGRID Admin Node
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Zur Wiederherstellung eines primären Admin-Knotens ist zunächst der Austausch der physischen oder virtuellen Hardware erforderlich.

Ein ausgefallener primärer Admin-Node kann durch einen primären Admin-Node ersetzt werden, der auf derselben Plattform läuft, oder ein primärer Admin-Node, der auf VMware oder einem Linux-Host läuft, kann durch einen primären Admin-Node ersetzt werden, der auf einer Services-Appliance gehostet wird.

Verwenden Sie das Verfahren, das der von Ihnen ausgewählten Ersatzplattform für den Node entspricht. Nach Abschluss des Node-Austauschverfahrens (das für alle Node-Typen geeignet ist), führt dieses Verfahren zum nächsten Schritt für die Wiederherstellung des primären Admin-Node.

 a|

 a|

 a|

 a| 
link:all-node-types-replacing-linux-node.html["Einen Linux-Knoten ersetzen"]



 a|

 a| 
link:replacing-failed-node-with-services-appliance.html["Austausch eines Servicegeräts"]



 a| 
OpenStack
 a| 
NetApp-bereitgestellte virtuelle Maschinen-Festplattendateien und Skripte für OpenStack werden für Wiederherstellungsvorgänge nicht mehr unterstützt. Wenn ein Knoten in einer OpenStack-Bereitstellung wiederhergestellt werden muss, stehen die Dateien für das jeweilige Linux-Betriebssystem zum Download bereit. Anschließend ist das Verfahren für link:all-node-types-replacing-linux-node.html["einen Linux Knoten ersetzen"] zu befolgen.
