= Verschieben Sie den ADC-Dienst in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können den ADC-Dienst auf einen anderen Storage Node am selben Standort verschieben.

.Bevor Sie beginnen
* Sie sind mit einem link:../admin/web-browser-requirements.html["unterstützte Webbrowser"] beim Grid Manager angemeldet.
* Du hast link:../admin/admin-group-permissions.html["${post_edited_translations.segment}"].
* Der Quellknoten enthält den ADC-Dienst.
* Der Zielknoten enthält den ADC Service nicht.
* Der Zielknoten ist entweder ein reiner Metadatenknoten oder ein kombinierter Knoten (Metadaten und Objektdaten).
* Quellknoten und Zielknoten befinden sich am selben Standort.


.Über diese Aufgabe
Die Move ADC-Prozedur kommt zum Einsatz, wenn Folgendes gewünscht wird:

* Einen Storage Node außer Betrieb nehmen, der den ADC-Service hostet
* Einen Speicherknoten, der den ADC-Dienst hostet, in einen reinen Datenspeicherknoten umwandeln


Wenn Sie einen Storage Node oder link:../maintain/convert-to-data-only-node.html["Einen Speicherknoten in einen reinen Datenknoten konvertieren"] außer Betrieb nehmen möchten, könnte zunächst die Move ADC-Prozedur erforderlich sein. Es muss sichergestellt werden, dass der link:../maintain/understanding-adc-service-quorum.html["Das ADC-Quorum wird aufrechterhalten"].

Dieses Verfahren verschiebt die Dienste ADC, IDNT, ACCT und RSM von einem Storage Node auf einen anderen am selben Standort. Die Dienste RSM, IDNT und ACCT sind vom Dienst ADC abhängig, daher werden sie automatisch verschoben, wenn der Dienst ADC verschoben wird.

.Schritte
. Die Knoten-IDs der Quell- und Zielknoten sind zu notieren.
+
In der Grid Management API wird die Quellknoten-ID als  `sourceNodeId` bezeichnet. Die Zielknoten-ID wird als  `targetNodeId` bezeichnet.

. Oben im Grid Manager das Hilfesymbol auswählen und anschließend *API documentation* wählen.
. *Zur privaten API-Dokumentation* auswählen.
. Die Operation  `POST /private/move-adc/start` auswählen. Weitere Informationen finden Sie unter link:../admin/using-grid-management-api.html#issue-api-requests["API-Anfragen ausführen"].
+
Während des Vorgangs werden die beiden Knoten nacheinander neu gestartet. Zuerst wird der Quellknoten neu gestartet, dann der Zielknoten.

. Sie können  `GET /private/move-adc` verwenden, um den Vorgang zu überwachen. Wenn Fehler auftreten,  `POST /private/move-adc/retry` auswählen, um den Vorgang zu wiederholen.
. link:../maintain/downloading-recovery-package.html["Ein Wiederherstellungspaket herunterladen"] nach Abschluss dieses Vorgangs.
