= Ersetzen Sie den StorageGRID-Speicherknoten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Wenn das Systemlaufwerk ausgefallen ist, muss zuerst der Storage Node ersetzt werden.

Sie müssen das Verfahren zum Ersetzen des Node für Ihre Plattform auswählen. Die Schritte zum Ersetzen eines Node sind für alle Arten von Grid-Nodes gleich.


NOTE: Dieses Verfahren gilt nur für softwarebasierte Storage Nodes. Ein anderes Verfahren ist erforderlich, um link:recovering-storagegrid-appliance-storage-node.html["einen Appliance Storage Node wiederherstellen"].

*Linux:* Wenn Sie sich nicht sicher sind, ob Ihre Systemfestplatte ausgefallen ist, können anhand der Anweisungen zum Austausch des Knotens die erforderlichen Wiederherstellungsschritte ermittelt werden.

[cols="1a,2a"]
|===
| Plattform | Verfahren 


 a| 
VMware
 a| 
link:all-node-types-replacing-vmware-node.html["Einen VMware-Knoten ersetzen"]



 a| 
Linux
 a| 
link:all-node-types-replacing-linux-node.html["Einen Linux-Knoten ersetzen"]



 a| 
OpenStack
 a| 
NetApp-bereitgestellte virtuelle Maschinen-Festplattendateien und Skripte für OpenStack werden für Wiederherstellungsvorgänge nicht mehr unterstützt. Wenn ein Knoten in einer OpenStack-Bereitstellung wiederhergestellt werden muss, stehen die Dateien für das jeweilige Linux-Betriebssystem zum Download bereit. Anschließend ist das Verfahren für link:all-node-types-replacing-linux-node.html["einen Linux Knoten ersetzen"] zu befolgen.

|===
