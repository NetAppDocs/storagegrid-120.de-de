= Ändern der DNS-Konfiguration für einen einzelnen StorageGRID-Knoten
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Anstatt DNS global für die gesamte Implementierung zu konfigurieren, kann ein Skript ausgeführt werden, um DNS für jeden Grid-Knoten unterschiedlich zu konfigurieren.

Im Allgemeinen wird empfohlen, die Option *Wartung* > *Netzwerk* > *DNS-Server* im Grid Manager zur Konfiguration der DNS-Server zu verwenden. Das folgende Skript ist nur zu verwenden, wenn für verschiedene Grid-Knoten unterschiedliche DNS-Server erforderlich sind.

.Schritte
. Der externe SSH-Zugriff ist standardmäßig blockiert. Falls erforderlich, link:../admin/manage-external-ssh-access.html["vorübergehend Zugriff erlauben"].
. ${post_edited_translations.segment}
+
.. Geben Sie den folgenden Befehl ein: `ssh admin@_primary_Admin_Node_IP_`
.. Geben Sie das in der  `Passwords.txt` Datei aufgeführte Passwort ein.
.. Geben Sie den folgenden Befehl ein, um zu root zu wechseln: `su -`
.. Geben Sie das in der  `Passwords.txt` Datei aufgeführte Passwort ein.
+
Wenn Sie als Root angemeldet sind, ändert sich die Eingabeaufforderung von  `$` zu  `#`.

.. Fügen Sie den privaten SSH-Schlüssel zum SSH-Agenten hinzu. Geben Sie Folgendes ein: `ssh-add`
.. Geben Sie das im  `Passwords.txt`-Datei aufgeführte SSH-Zugriffspasswort ein.


. [[log_in_to_node]]Bei dem Knoten anmelden, der mit einer benutzerdefinierten DNS-Konfiguration aktualisiert werden soll: `ssh _node_IP_address_`
. Das DNS-Setup-Skript ausführen: `setup_resolv.rb.`
+
Das Skript antwortet mit der Liste der unterstützten Befehle.

+
[listing]
----
Tool to modify external name servers

available commands:
  add search <domain>
               add a specified domain to search list
               e.g.> add search netapp.com
  remove search <domain>
               remove a specified domain from list
               e.g.> remove search netapp.com
  add nameserver <ip>
               add a specified IP address to the name server list
               e.g.> add nameserver 192.0.2.65
  remove nameserver <ip>
               remove a specified IP address from list
               e.g.> remove nameserver 192.0.2.65
  remove nameserver all
               remove all nameservers from list
  save         write configuration to disk and quit
  abort        quit without saving changes
  help         display this help message


Current list of name servers:
    192.0.2.64
Name servers inherited from global DNS configuration:
    192.0.2.126
    192.0.2.127
Current list of search entries:
    netapp.com

Enter command [`add search <domain>|remove search <domain>|add nameserver <ip>`]
              [`remove nameserver <ip>|remove nameserver all|save|abort|help`]
----
. Die IPv4-Adresse eines Servers, der den Domain Name Service für Ihr Netzwerk bereitstellt, hinzufügen: `add <nameserver IP_address>`
. Der  `add nameserver` Befehl kann wiederholt werden, um Nameserver hinzuzufügen.
. Den Anweisungen für weitere Befehle ist entsprechend der Aufforderung zu folgen.
. Speichern Sie Ihre Änderungen und beenden Sie die Anwendung: `save`
. [[close_cmd_shell]]Die Befehlsshell auf dem Server wird geschlossen: `exit`
. Für jeden Gitterknoten sind die Schritte von <<log_in_to_node,Anmeldung am Knoten>> bis <<close_cmd_shell,Schließen der Befehlsshell>> zu wiederholen.
. Wenn kein passwortloser Zugriff auf andere Server mehr erforderlich ist, sollte der private Schlüssel aus dem SSH-Agenten entfernt werden. Eingabe: `ssh-add -D`
. Wenn Sie den externen SSH-Zugriff zugelassen haben, link:../admin/manage-external-ssh-access.html["Blockzugriff"] sobald Sie die Änderung der DNS-Konfiguration abgeschlossen haben.
