= Entfernte oder veraltete Funktionen und Fähigkeiten in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Informieren Sie sich über die in StorageGRID 12.0 entfernten oder als veraltet markierten Funktionen und Möglichkeiten. Prüfen Sie vor dem Upgrade, ob entfernte oder veraltete Funktionen Ihre Clientanwendungen oder die Grid-Konfiguration beeinträchtigen.



[[definitions]]
== Definitionen

Veraltet:: Diese Funktion sollte *nicht* in neuen Produktionsumgebungen verwendet werden. In bestehenden Produktionsumgebungen kann die Funktion weiterhin verwendet werden.
Lebensende:: Die letzte ausgelieferte Version, die diese Funktion unterstützt. In manchen Fällen kann die Dokumentation für diese Funktion in diesem Stadium entfernt werden.
Entfernt:: Erste Version, die die Funktion *nicht* unterstützt.




[[storagegrid-end-of-feature-support]]
== StorageGRID Ende der Funktionsunterstützung

Veraltete Funktionen werden in den N+2 Hauptversionen entfernt. Wenn eine Funktion beispielsweise in Version N (zum Beispiel 6.3) als veraltet markiert wird, ist die letzte Version, in der diese Funktion vorhanden ist, N+1 (zum Beispiel 6.4). Version N+2 (zum Beispiel 6.5) ist die erste Version, in der die Funktion nicht mehr im Produkt enthalten ist.

Weitere Informationen sind unter  https://mysupport.netapp.com/site/info/version-support["Seite zur Unterstützung von Softwareversionen"^] verfügbar.


NOTE: In bestimmten Situationen kann NetApp die Unterstützung für bestimmte Funktionen früher als angegeben einstellen.
