= Beispiel für eine StorageGRID S3 REST API-Sitzungsrichtlinie
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das folgende Beispiel dient zum Erstellen einer StorageGRID Sitzungsrichtlinie.



[[example-set-up-a-session-policy-that-allows-object-retrieval]]
== Beispiel: Eine Sitzungsrichtlinie, die den Abruf von Objekten ermöglicht, einrichten

In diesem Beispiel darf der Sitzungsbenutzer nur Objekte aus bucket1 abrufen. Alle anderen Aktionen sind implizit untersagt, mit Ausnahme von StorageGRID-spezifischen Aktionen, wie der Verwendung der link:../s3/use-access-policies.html#use-putoverwriteobject-permission["s3:PutOverwriteObject"] Berechtigung. Die Sitzungsrichtlinie kann beim Aufruf der AssumeRole API als JSON-Datei angegeben werden.

[listing]
----
{
  "Statement": [
    {
      "Action": "s3:GetObject",
      "Effect": "Allow",
      "Resource": "arn:aws:s3:::bucket1/*"
    }
  ]
}
----
