= Unterstützte Serviceoperationen in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Das StorageGRID System unterstützt die folgenden Operationen für den Dienst.

[cols="1a,2a"]
|===
| Betrieb | Implementierung 


 a| 
ListBuckets

(früher als GET Service bezeichnet)
 a| 
Implementiert mit dem gesamten Verhalten der Amazon S3 REST API. Änderungen vorbehalten.



 a| 
Speichernutzung abrufen
 a| 
Die StorageGRID link:get-storage-usage-request.html["Speichernutzung abrufen"] Anfrage gibt die gesamte vom Konto und von jedem mit dem Konto verknüpften Bucket genutzte Speichermenge an. Dies ist eine Operation für den Service mit dem Pfad / und einem benutzerdefinierten Abfrageparameter (`?x-ntap-sg-usage` hinzugefügt.



 a| 
OPTIONEN /
 a| 
Clientanwendungen können  `OPTIONS /`Anfragen an den S3-Port eines Storage Node senden, ohne S3-Authentifizierungsdaten bereitzustellen, um festzustellen, ob der Storage Node verfügbar ist. Diese Anfrage kann für die Überwachung verwendet werden oder um externen Load Balancern zu ermöglichen, zu erkennen, wenn ein Storage Node ausgefallen ist.

|===
