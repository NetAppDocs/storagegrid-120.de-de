= Unterstützte Amazon S3 Select-Operationen in StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID unterstützt die folgenden Amazon S3 Select Klauseln, Datentypen und Operatoren für die link:select-object-content.html["SelectObjectContent Befehl"].


NOTE: Alle nicht aufgeführten Artikel sind nicht unterstützt.

Informationen zur Syntax sind unter link:select-object-content.html["SelectObjectContent"] zu finden. Weitere Informationen zu S3 Select sind unter  https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html["AWS Dokumentation für S3 Select"^] zu finden.

Nur Mandantenkonten, für die S3 Select aktiviert ist, können SelectObjectContent-Abfragen ausführen. Siehe link:../admin/manage-s3-select-for-tenant-accounts.html["Überlegungen und Anforderungen für die Verwendung von S3 Select"].
