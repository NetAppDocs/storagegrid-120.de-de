[[storagegrid-custom-error-codes]]
== StorageGRID benutzerdefinierte Fehlercodes

[cols="2a,2a,1a"]
|===
| Name | Beschreibung | HTTP Status 


 a| 
XBucketLifecycleNotAllowed
 a| 
Die Bucket-Lifecycle-Konfiguration ist in einem Legacy Compliant Bucket nicht zulässig.
 a| 
400 Fehlerhafte Anfrage



 a| 
XBucketPolicyParseException
 a| 
Fehler beim Parsen des empfangenen Bucket-Policy-JSON.
 a| 
400 Fehlerhafte Anfrage



 a| 
XComplianceConflict
 a| 
Vorgang aufgrund veralteter Compliance-Einstellungen abgelehnt.
 a| 
403 Forbidden



 a| 
XComplianceReducedRedundancyForbidden
 a| 
Reduzierte Redundanz ist in älteren Compliant Buckets nicht zulässig.
 a| 
400 Fehlerhafte Anfrage



 a| 
XMaxBucketPolicyLengthExceeded
 a| 
Ihre Richtlinie überschreitet die maximal zulässige Bucket-Richtlinienlänge.
 a| 
400 Fehlerhafte Anfrage



 a| 
XMissingInternalRequestHeader
 a| 
Es fehlt ein Header einer internen Anfrage.
 a| 
400 Fehlerhafte Anfrage



 a| 
XNoSuchBucketCompliance
 a| 
Für den angegebenen Bucket ist die Legacy Compliance nicht aktiviert.
 a| 
404 Nicht gefunden



 a| 
XNotAcceptable
 a| 
Die Anfrage enthält einen oder mehrere Accept-Header, die nicht erfüllt werden konnten.
 a| 
406 Nicht akzeptabel



 a| 
XNotImplemented
 a| 
Die von Ihnen bereitgestellte Anfrage impliziert eine Funktionalität, die nicht implementiert ist.
 a| 
501 Nicht implementiert

|===
