= Workflow-Zusammenfassung für das Hinzufügen von Grid-Knoten oder neuen Standorten zu StorageGRID
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Führen Sie dieses Verfahren aus, um bestehenden Standorten Grid-Nodes hinzuzufügen oder einen neuen Standort hinzuzufügen. Es kann jeweils nur eine Art der Erweiterung durchgeführt werden.

.Bevor Sie beginnen
* Sie haben die link:../admin/admin-group-permissions.html["Root-Zugriff oder Wartungsberechtigung"].
* Alle bestehenden Knoten im Grid sind an allen Standorten betriebsbereit.
* Sämtliche zuvor durchgeführten Erweiterungs-, Modernisierungs-, Stilllegungs- oder Wiederherstellungsverfahren sind abgeschlossen.
+

NOTE: Sie werden daran gehindert, eine Erweiterung zu starten, solange eine andere Erweiterung, ein Upgrade, eine Wiederherstellung oder eine aktive Stilllegungsprozedur ausgeführt wird. Falls erforderlich, kann jedoch eine Stilllegungsprozedur unterbrochen werden, um eine Erweiterung zu starten.



.Schritte
. link:updating-subnets-for-grid-network.html["Subnetze für das Grid Network aktualisieren"].
. link:deploying-new-grid-nodes.html["Die neuen Grid-Knoten bereitstellen"].
. link:performing-expansion.html["Die Erweiterung durchführen"].
