= Die StorageGRID Systempasswörter angeben
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Im Rahmen der Installation Ihres StorageGRID Systems müssen die Passwörter eingegeben werden, die zum Schutz Ihres Systems und zur Durchführung von Wartungsaufgaben verwendet werden.

.Über diese Aufgabe
Auf der Seite „Installationskennwörter“ lassen sich die Bereitstellungs-Passphrase und das Root-Benutzer-Kennwort für die Grid-Verwaltung festlegen.

* Die Bereitstellungspassphrase wird als Verschlüsselungsschlüssel verwendet und vom StorageGRID System nicht gespeichert.
* Sie benötigen die Bereitstellungskennung für Installations-, Erweiterungs- und Wartungsvorgänge, einschließlich des Herunterladens des Wiederherstellungspakets. Daher ist es wichtig, die Bereitstellungskennung an einem sicheren Ort aufzubewahren.
* Sie können die Bereitstellungspassphrase im Grid Manager ändern, sofern Sie die aktuelle Passphrase besitzen.
* Das Root-Benutzer-Passwort für die Grid-Verwaltung kann mit dem Grid Manager geändert werden.
* Zufällig generierte Befehlszeile- und SSH-Passwörter werden in der  `Passwords.txt` Datei im Wiederherstellungspaket gespeichert.


.Schritte
. Im Feld *Bereitstellungspassphrase* ist die Bereitstellungspassphrase einzugeben, die erforderlich ist, um Änderungen an der Grid-Topologie Ihres StorageGRID Systems vorzunehmen.
+
Die Bereitstellungs-Passphrase sollte an einem sicheren Ort aufbewahrt werden.

+

NOTE: Wenn nach Abschluss der Installation die Bereitstellungs-Passphrase später geändert werden soll, kann dafür der Grid Manager verwendet werden. *Konfiguration* > *Zugriffskontrolle* > *Grid passwords* auswählen.

. Unter *Bereitstellungspassphrase bestätigen* wird die Bereitstellungspassphrase erneut eingegeben, um sie zu bestätigen.
. Im Feld *Grid Management Root User Password* das Passwort eingeben, das für den Zugriff auf den Grid Manager als „Root“-Benutzer verwendet wird.
+

CAUTION: Die Bereitstellungspassphrase ist an einem sicheren Ort aufzubewahren. Sie wird für Installations-, Erweiterungs- und Wartungsverfahren benötigt.

. In *Root-Benutzerpasswort bestätigen* wird das Grid Manager-Passwort erneut eingegeben, um es zu bestätigen.
+
image:10_gmi_installer_passwords_page.gif["Dieses Bild wird im umgebenden Text erläutert."]

. Wenn ein Grid zu Proof-of-Concept- oder Demonstrationszwecken installiert wird, kann optional das Kontrollkästchen *Zufällige Befehlszeilenpasswörter erstellen* deaktiviert werden.
+
Für Produktionsumgebungen sollten aus Sicherheitsgründen stets zufällige Passwörter verwendet werden. *Zufällige Befehlszeilenpasswörter erstellen* sollte nur für Demo-Grids deaktiviert werden, wenn Standardpasswörter für den Zugriff auf Grid-Knoten über die Befehlszeile mit dem „root“- oder „admin“-Konto verwendet werden sollen.

+

NOTE: Sie werden aufgefordert, die Wiederherstellungspaketdatei (`sgws-recovery-package-id-revision.zip` herunterzuladen, nachdem auf der Übersichtsseite auf *Installieren* geklickt wurde. Sie müssen link:../maintain/downloading-recovery-package.html["Diese Datei herunterladen"], um die Installation abzuschließen. Die für den Systemzugriff erforderlichen Passwörter sind in der im Wiederherstellungspaket enthaltenen  `Passwords.txt` Datei gespeichert.

. Klicken Sie auf *Weiter*.
